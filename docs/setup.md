# Setup Guide - Customer Service Booking

Follow these steps to get the project running on your local machine.

## Prerequisites

- **Android Studio**
- **JDK**: Java 17 or higher.
- **Android SDK**: API Level 37 (Android 15) is required for compilation.

## Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Chmpragyan/Customer-Service-Booking.git
    ```
2.  **Open in Android Studio**:
    - Launch Android Studio.
    - Select **Open** and navigate to the project root folder.
3.  **Sync Gradle**:
    - Android Studio should automatically prompt you to sync. If not, go to **File > Sync Project with Gradle Files**.

## Running the App

1.  **Select a Device**:
    - Use a physical Android device or an Emulator (API 24+).
2.  **Build and Run**:
    - Click the **Run** button (green play icon) in the toolbar.

## Project Structure Overview

- `app/src/main/java`: Contains the Kotlin source code.
- `app/src/main/res`: Contains UI resources (strings, themes).
- `docs/`: Contains API and Architecture documentation.

## Testing Simulated Scenarios

The app includes a mock data layer to test various UI states without a backend.
